# Changelog

## [0.1.0] - 2026-06-03

### Added

- Initial release
- Shell history parser for bash and zsh
- SQLite-backed storage with commands and chains tables
- Context-aware command predictions based on current directory
- Command prefix completion
- Fish shell plugin generator
- Zsh shell plugin generator
- CLI with subcommands: learn, predict, complete, stats, install
- CI pipeline (GitHub Actions) with build, lint, and test
- Release workflow for Linux, macOS, and Windows
- Comprehensive README with installation and usage guides
- Integration tests covering all CLI commands
- Shell integration scripts for Fish and Zsh
- Install script for Unix systems
- Contributing guidelines
